## Data & Open Working Time

- We start with small example datasets
- We will discuss Big Data handling
- Open Working Time is for YOUR data and projects - we are here to help!
- Form groups to learn from each other and be most effective

---

## Focus

- Sharing knowledge within and across domains
- Open Source tools, usability, reproducibility
- Use case specific solutions
  - graphical user interfaces for interactive exploration
  - headless rendering for batch processing
  - HPC compatibility for Big Data handling
